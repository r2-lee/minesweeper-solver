# 「首点位置 × Hill 升级版」大规模跑盘 —— 最终结果

**状态：已完成**（2026-11-19 19:45，201 主机）。共 **2,300,000 局**：120 格网格 120 万局 + 11 个重点位置各 10 万局。

## 配置

- 求解器：Hill 升级版 `LARGE_ADAPTIVE_ANALYSIS`（`~/mine_hill/hill/hill-worker.jar`，JDK 21 在 `~/jdk21`）
- 棋盘：高级 16×30 / 99 雷，首点九宫格无雷
- 每位置 100,000 局；28 进程 × 每块 250 局；约 **15 分钟 / 10 万局**
- 首点坐标按 `(row, col)`，从 0 开始；网格只跑左上 1/4（120 格），其余按行列镜像补全

## 结论

1. **最强信号是"别点角"**：(0,0) 只有 48.57%，比中心低 4.8 点（z=−21.6），比 (3,3) 低 6.0 点。角上首点最多只揭开 4 格（九宫格被边界裁掉），后面要多猜 0.5 次（3.17 vs 2.67）。
2. **次强信号是"贴边的中点也不好"**：(0,14) 52.14%（z=−5.6）、(1,1) 51.89%（z=−6.7）。
3. **右上（左上镜像）那块 (2,2)~(3,3) 确实偏甜**：54.57% / 54.24%，比中心高 1.2 / 0.9 点，是目前唯一显著高于中心的位置。之前 833 局时的 58.6% 是噪声上沿，10 万局后回落到 54.6%，但仍然显著。
4. **(4,4) 没有特殊性**：833 局时 55.5% 的"高点"在 10 万局后回落到 53.42%，与中心、网格均值一致。
5. 猜测次数与胜率强相关：每局 3.17 次（角）→ 2.65 次（(3,3)），基本就是 `P ≈ q^n` 在起作用。

**实用建议**：在 16×30 高级盘上，首点选**距角 2~3 格的内部位置**（如 (3,3)，四角镜像皆可），比点正角期望高约 **+6 点**；点边线中点比角好约 +3.6 点。

## 踩过的坑（留给下次）

- `hill_heatmap.py` 早期版本按"位置"切任务，**单位置大样本会全压在一个 worker 上**（40 万局要 24 h）；现在按 250 局一块切，28 路并行。
- 停任务别用 `pkill -f`（会漏掉 java 子进程，残留过 85 个）；用 `bash ~/kill2.sh`，再用 `bash ~/state.sh` 确认 `java=0 py=0`。
- `python3 ... | head` 与 `multiprocessing.Pool` 同用会因 SIGPIPE 挂死，日志一律重定向到文件。
- 201 的登录 shell 是 fish，`for`/`$()` 用不了，远端脚本一律 `bash ~/xxx.sh`。

## 复核（独立种子，50,000 局/点）

| 位置 | 主实验（seed 4101–4111，10 万局） | 复核（seed 7101–7103，5 万局） | 合并 15 万局 |
|---|---|---|---|
| (3,3) | 54.57% | **54.85%** | **54.59%** |
| (2,2) | 54.24% | 54.36% | 54.14% |
| (8,15) 中心 | 53.38% | 53.14% | 53.27% |

- (3,3) − 中心：主实验 +1.19 点（z=5.3）、复核 **+1.71 点（z=5.4）**、合并 **+1.32 点（z≈7.2）** → 结论稳固，不是种子运气。
- (3,3) − (2,2)：合并 +0.45 点（z≈1.6），两者谁高仍未分出来；(3,3) 至少不劣于 (2,2)，且两次都排在前面。
- 猜测次数几乎不随位置变（2.65 / 2.66 / 2.71）→ 首点影响的是"你要不要猜"，不是"猜几次"。
