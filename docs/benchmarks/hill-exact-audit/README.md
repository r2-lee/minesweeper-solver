# Hill 与 EdLogg 首猜离线精确对照

在 199 个专家盘局面上都算出了最优整局胜率，以及固定采用 Hill 或 EdLogg 的首猜后能达到的最优整局胜率。这些数值包含当前这一猜的踩雷风险。

| 选点 | 平均整局胜率 | 平均损失 | 选到最优 | 至少损失 1 个百分点 | 最大损失 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 精确搜索 | 56.3049% | 0 | 199 | 0 | 0 |
| Hill | 55.8373% | 0.4677 个百分点 | 134 | 35 | 6.2919 个百分点 |
| EdLogg | 55.4707% | 0.8342 个百分点 | 120 | 49 | 11.2848 个百分点 |

Hill 的选点占优 41 局，EdLogg 占优 23 局，135 局打平。逐局取两者中较好的选点，仍有 27 局损失至少 1 个百分点，其中 13 局两边点的是同一个格子。

## 哪些状态值得加深

测试了一个便宜的筛选规则。对候选首猜使用同一个简单续局策略，确定安全且有信息量的格子先开，必须猜时优先选存活概率最高的格子。用所有一致雷图精确统计这套固定策略能赢多少张。若最好的候选估分比当前选点高至少 0.5 个百分点，就把该状态送去加深搜索。两个估分的差用作筛选信号，真正的收益由精确搜索测量。

| 当前选点 | 触发数 | 捕获损失至少 1 个百分点的局面 | 捕获的总精确损失 |
| --- | ---: | ---: | ---: |
| Hill | 77 / 199 | 33 / 35 | 91.8% |
| EdLogg | 91 / 199 | 46 / 49 | 95.9% |
| 逐局取两者中较好的选点作为基准 | 66 / 199 | 25 / 27 | 92.5% |

若在 Hill 上只用「两套算法选点不同」触发，则搜索 100 局，只抓到 Hill 的 22 / 35 个大损失局面。按候选雷图数切成小于 1 万、1 万到不足 2 万、2 万到 4 万三段，分别有 8 / 54、9 / 68、10 / 77 个局面可比两者中较好的选点再提高至少 1 个百分点。

`2026-90-3` 有 25,032 张候选雷图。Hill 和 EdLogg 都点第 16 行第 4 列。第 16 行第 3 列的首猜更险，却显著降低后面的风险。

| 首猜 | 本手安全率 | 存活后的最优续局胜率 | 从当前算起的最优整局胜率 |
| --- | ---: | ---: | ---: |
| 两边原选点 | 79.77% | 65.03% | 51.87% |
| 最优选点 | 71.25% | 81.63% | 58.17% |

候选雷图和数字矩阵已经准备好时，筛选阶段单局墙钟耗时中位数为 0.103 秒，95 分位为 0.312 秒。每局取各精确求解器最快的完整结果，耗时中位数为 1.17 秒，95 分位约 14.63 秒，最长约 36.91 秒。这些计时来自本机的并发离线运行，矩阵生成时间单独计算。0.5 个百分点是本次回放的试验阈值，收益要用新发牌的整局同盘 A/B 衡量。

## 实验口径

专家盘为 16×30、99 雷，首点固定 `(3,3)` 且保证开出 0。检查种子 2026 和 9127 各前 2,500 张盘，提取每盘首个符合条件的 Hill 决策。199 局均为候选雷图至多 40,000 张且 Hill 的全盘搜索超过 `LARGE_ANALYSIS` 预算。其中 189 局因门槛跳过，10 局超出枚举迭代上限。表中均值按局面等权，适用范围为这 199 个选定局面。

Hill 版本 `827e5b9b898ec9b8a8b03383b42a374ad12586b1`。EdLogg 版本 `2e8868d737bf4e5de79ea9b711a30a51d9debe64`。两套算法拿到同一份可见数字和已确认雷。全盘精确搜索按剩余雷图上的赢局整数计分，并在不同实现间合并一致的证明结果。24 个已知全盘精确残局在交叉验证中吻合，数字观察模型还逐格通过了与实际零格连锁展开对照的 185 张小盘。

若两手的存活雷图集合相同，这两手的精确价值相同。本批有 133 个这样的局面。筛选阶段可以合并这类候选，同时保留对第三个候选搜索的机会。

## 逐局数据与复算

- [逐局精确评分](results.tsv) 中，`layout_count` 是分母，`v_lo` 是最优赢局数，`hill_lo` 和 `edlogg_lo` 是固定相应首猜后能赢的张数。同名 `hi` 等于 `lo` 即为精确值。格子编号从零开始，按行排列。
- [触发筛选数据](triage.tsv) 给出了每局的真实损失、便宜估分的差值和触发结果。
- [复算资料](evidence.zip) 包含局面、EdLogg 原选点、各批证明记录及本地搜索工具源码。解压后可用相同项目中的约束枚举器重建矩阵，再合并搜索记录。

运行环境为 Python 3.10 或以上。将下面命令里的 `<项目路径>` 换成 PyStand-py38-pyqt5-lite 的实际路径。

~~~powershell
python prepare_matrices.py "<项目路径>" hill/study-primary.tsv edlogg/ed-primary-canonical.tsv primary-matrices
python merge_current.py --output replay
~~~
